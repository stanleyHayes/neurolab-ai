# Focused deterministic replay routing

The 2026-10-27 recorded-answer review found that default focused replay repeatedly returned contrast/ranking content for missingness/source questions. This increment changes automatic method selection and direct report wording; it does not change scientific numeric tools or enable Meta.

## Precedence and scope

1. An accepted objective-bound plan remains authoritative.
2. Explicitly selected preferred methods remain authoritative, including their order.
3. The full Ghana investigation output uses its six-method/four-criterion contract.
4. Otherwise, `focused_planning.py` applies documented keyword rules to the objective.

Matched topics are recorded in the persisted plan's constraints. This is a heuristic, not a model call, full language comprehension or a guarantee that every requested scientific operation is supported. The original text remains exact. Common imperative exclusions (`do not`, `don't`, `skip`, `exclude`, `avoid`, `without running/calculating/computing`) are masked through the next clause boundary before matching. Complex negation, quoted passages, multilingual objectives and ambiguous references can still require explicit method selection. No text can introduce a new action or execute code: matches map only to the fixed schema/registry methods.

| Topic cues | Selected method |
|---|---|
| Profile, source, records/rows, provenance, ENVT/calendar, how many plots | Dataset profile |
| Missing/absent/incomplete values, data quality | Missingness audit |
| Correlation/association, ASI, flowering or stay-green cues | Drought trait associations |
| Stability/variability/variation/sensitivity, across environments, omit-one environment | Observed environment sensitivity |
| Rank, candidate, which/best genotype | Descriptive genotype ranking |
| Compare/comparison, contrast, retention, denominator, ratio, causal/irrigation, adjacent drought/watered comparison | Regime contrast |

Multiple topics select all matched methods in this table's order, without duplicates. Budgets limit execution, not the stored plan: unexecuted tasks remain pending and the report is partial. This fixed ordering prioritizes metadata and missingness before expensive interpretation when requested. It is not an optimized research scheduler. Unknown wording retains the generic contrast/ranking/missingness fallback and records an unresolved planning note, now visible in the persisted-plan UI. Select explicit methods to resolve ambiguity.

Default configuration currently permits three steps. A broad objective that matches more methods can therefore remain partial. Use the explicit full investigation preset for the complete supplied maize case; the heuristic does not silently truncate an investigation or redefine its completion.

## Direct report statements

- Regime comparisons now state whether observed retention is available and its actual percentage when defined. They state the positive watered-mean denominator requirement, null fallback and noncausal scope. Ratios above 100% remain intact.
- Ranking claims explicitly say they estimate neither rank confidence intervals nor rank probabilities, and do not adjust alpha-lattice effects or multiplicity. Candidates remain research leads rather than field recommendations.
- Source profiles directly include observed plot counts for each regime, in addition to overall plot/genotype/environment counts.
- Completion status is explicitly about the accepted method tasks, not proof of complete semantic coverage of the objective.

All statements derive from existing validated numeric artifacts. No new observations, uncertainty estimator or model narrative is introduced. Historical reports/exports/reviews remain immutable; new generation wording does not rewrite them.

## Validation boundaries

Tests cover paraphrases, common exclusions, explicit-method/accepted full-profile precedence, fallback disclosure, actual one-call missingness/source/ratio/ranking answers and retained pending tasks under a one-call budget. The existing trace test now pins its original explicit three-method contract so automatic-routing changes do not erase its evidence-sequence assertions. A budget test exposed a missing `compare` alias; the alias was fixed while preserving the test's partial/terminal-state assertions.

The original twelve evaluation questions are already known and informed these fixes. Any rerun is a regression check on that known set, not a held-out benchmark or evidence of general language competence. New results must preserve earlier failures and annotations and must not inherit stale review ratings. Non-blind assistant review remains distinct from independent human/live Meta acceptance.
