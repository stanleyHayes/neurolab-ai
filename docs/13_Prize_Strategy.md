# 13 — Prize strategy without scope dilution

## Main tracks
Indie Developer $150K/$100K/$75K/$50K/$25K; Startups $250K/$150K/$75K/$50K/$25K. Select track per organizer eligibility; no assumption a startup automatically qualifies for Indie. Stage 1 pass/fail on theme and meaningful Meta use; Stage 2 four equally weighted categories (Impact, Meta AI Tooling, Technical Depth, Demo), 0–10 each; top five per track reach final judging.

## Bonus prize design
**Best Agentic Use-Case ($5K, P0):** Real bounded scientific agent chooses follow-up analysis based on previous evidence. Demonstrate trace, failure recovery, and measurable advantage over fixed/random selection.

**Best Meta Open-Weight Build ($10K, P1):** Integrate Muse Glimmer or Muse Spark Open *as an actual working inference path*, run on own hardware or approved partner. Capture provider/model ID and reproducible test. Baseten hackathon docs specify `meta-models/muse-spark-open-1026` rather than generic name; verify partner and availability.

**Most Viral ($20K, P1 distribution):** Publish genuine project demo on X, submit post link, invite authentic engagement; award determined by engagement through Nov 8 EOD per guide. Do not manipulate engagement or misrepresent results.

**Community Vote ($10K, P1):** Publish compelling gallery entry and ask supporters for one verified-account vote; announced Nov 16.

**Best Creative Build ($5K, P2):** Requires effective Muse Image or Muse Wonder use, not merely fancy GSAP visuals. Only pursue if genuinely useful for explaining experiments and actual model integration can be shown.

## Priority order
Main-track viability + Agentic bonus > eligible open-weight integration > authentic outreach > creative optionality. No prize is guaranteed and stacking is not assumed.
