# 14 — Three-minute judged demo storyboard

**0:00–0:18 — Hook.** 'Testing drought-resilient maize across years and treatments is difficult. NeuroLab accelerates the research *analysis*, not the field trial.' Show Ghana dataset source DOI and trial design.

**0:18–0:38 — Real evidence.** Show 864 Ghana plot records, 72 genotypes, two regimes, three environments; click provenance and uncertainty.

**0:38–1:08 — Agent hypothesis.** Researcher asks which genotypes retain yield under drought. Show Meta model ID and structured proposed hypothesis/action; validated server-side.

**1:08–1:48 — Closed-loop research.** Tool computes measured comparisons; model reads result and selects a second analysis to check stability or confounding. Show actual SSE event stream and computed charts.

**1:48–2:17 — Scientific insight.** Present strongest *candidate for follow-up research* with uncertainty and limitations, not guaranteed field result. Reveal raw records and reproducibility report.

**2:17–2:40 — Engineering and baseline.** Show evaluation against fixed/random tool choice and how safety gate rejects invalid experiment, using actual measured numbers only.

**2:40–3:00 — Impact and close.** Show public code, dataset credits, reproducible report and model inference provider. End with 'From a research question to auditable evidence in minutes.'
