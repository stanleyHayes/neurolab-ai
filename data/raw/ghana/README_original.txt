Phenotypic data for drought-tolerance evaluation of African maize landraces

Files
-----
maize_drought_phenotypes.csv      432 plot records, managed drought stress
maize_wellwatered_phenotypes.csv  432 plot records, well-watered control
maize_combined_phenotypes.csv     864 plot records, both regimes stacked
data_dictionary.csv               column names, descriptions, and units

Design
------
Seventy-two accessions (68 landraces from 13 African countries plus four elite
check populations) were evaluated in a 9 x 8 alpha-lattice design with two
replications per environment. Each watering regime was run over three trial
years (ENVT 1-3) at the West Africa Centre for Crop Improvement, University of
Ghana, between 2020 and 2023. The drought file carries two extra columns absent
from the well-watered trial (GENO alias code, STYG stay-green score); in the
combined file STYG is left blank for well-watered rows.

Use
---
The two per-regime files were the direct inputs to the mixed-model analysis in
the accompanying manuscript. The combined file stacks them with a CONDITION flag
and a six-level ENV factor for the combined-environment model.
