## Minimum demo milestone

Before recording, require one live Meta-powered scientific experiment on Ghana that:

1. Displays the true objective and a falsifiable hypothesis with model/provider provenance.
2. Inspects the source profile and runs an environment-aware drought genotype analysis with a defensible stability definition/uncertainty treatment.
3. Makes at least two useful follow-up decisions that explicitly cite previous persisted evidence IDs.
4. Reports real deterministic values, method, filters, sample sizes, uncertainty and caveats; no fabricated fields.
5. Chooses a next trial design tied to observed limitations and clearly labels it as a suggestion.
6. Repeats deterministic computations from the same source hash/config/seed.
7. Is visible in the actual browser UI; event timeline maps to backend event records; errors/recovery and provider/model labels are honest.
8. Runs in an accessible staging environment and is captured in <=180 seconds with source/licensing, uncertainty, code attribution and setup visible.
